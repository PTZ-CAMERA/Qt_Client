# 개발 세션 기록 — 2026-10-02 (한국 시간)

## 오늘 한 일

- Qt 소스를 역할별로 정리했다. `app/`는 앱 시작점과 메인 화면, `camera/`는 재생 방식 선택과 데모 화면, `camera/rtsp/`는 RTSP 플레이어, `camera/webrtc/`는 WebRTC 플레이어, `network/`는 Pi TCP 통신, `ui/`는 조작 패널, `model/`은 추적 데이터 구조를 담당한다. CMake 소스 경로와 문서 링크도 갱신했다.
- Pi 연결을 시도했지만 이 관리형 WSL 환경에서 `192.168.0.92`의 영상 포트 `8889`·`8554`와 제어 포트 `5000`으로 나가는 소켓이 모두 `Operation not permitted`로 차단됐다. 이는 Pi 서비스가 꺼졌다는 판정이 아니다.
- 사용자에게서 Pi 서보 코드가 터미널의 `a/d/w/s/c` 키와 GPIO17 중앙 복귀 버튼으로 동작한다는 내용을 받았다. Qt는 방향키·화면 버튼을 `PTZ:LEFT/RIGHT/UP/DOWN/CENTER`와 줄바꿈으로 TCP에 보낸다. 방향별 각도 의미는 대응하지만, 제공된 서보 코드 자체에는 TCP 수신부가 없었다. 이후 사용자가 Pi 서버에 TCP를 만들었다고 알렸으나 서버 구현과 실동작은 아직 확인하지 못했다.
- TCP 미연결 상태에서 PTZ 버튼을 눌러도 명령을 보낸 것처럼 로그가 찍히던 점을 수정했다. 이제 미연결이면 `not sent` 로그를 남긴다.
- 카메라 재생 선택기를 `WebRTC / RTSP TCP / RTSP UDP` 세 가지로 늘렸다. 기본값은 WebRTC다. RTSP 재생을 시작할 때 Qt FFmpeg의 `QT_FFMPEG_RTSP_TRANSPORT`를 선택값으로 지정하며, 모드 변경 시 이전 재생을 중지한다. 선택 이유와 한계는 [0003 기술 결정](../tech-decisions/0003-selectable-rtsp-transport.md)에 기록했다.
- 현재 Qt RTSP 코드에는 수신 버퍼 시간이나 크기를 직접 설정하지 않았음을 확인했다. `QMediaPlayer`의 기본 재생 방식에 맡기고 있으며, 150~250ms는 적용값이 아니다. 영상이 10초간 진행하지 않을 때 표시하는 오류 시간은 수신 버퍼가 아니다. WebRTC에도 별도 버퍼 시간 설정은 없다.
- FFmpeg가 RTSP 경로에서 압축 영상을 읽고 해독하는 Qt Multimedia 백엔드라는 점과, H.264·RTSP·TCP/UDP의 역할 차이를 정리했다.

## 확인 결과와 제한

- CMake에 등록된 소스/헤더 목록과 실제 파일 20개가 일치하고, 프로젝트 내부 `#include` 경로 누락이 없다. `git diff --check`도 통과했다.
- 이 WSL 환경에는 `cmake` 명령이 없고 Windows 실행 연동도 이전에 실패했다. 이번 폴더 정리 및 RTSP UDP 추가 이후의 **Windows Qt 빌드는 완료하지 못했다**.
- Pi 네트워크 접속이 작업 환경에서 차단되어 WebRTC, RTSP TCP/UDP 실재생과 TCP 5000 서보 제어는 검증하지 못했다. Pi가 UDP 전송을 허용하는지도 확인이 필요하다.
- 코드 변경은 작업 트리에 남아 있으며 이 세션에서는 커밋·푸시하지 않았다.

## 다음 작업

1. Windows Qt Creator에서 저장소 최상위 `CMakeLists.txt`를 MSVC Kit으로 새 빌드 디렉터리에 구성하고 빌드한다.
2. 앱에서 `WebRTC`, `RTSP TCP`, `RTSP UDP`를 각각 선택해 실제 프레임이 표시되고 상태가 `PLAYING`으로 바뀌는지 확인한다. UDP가 실패하면 Pi RTSP 서버의 UDP 허용 여부와 네트워크 경로를 확인한다.
3. Connection의 `192.168.0.92:5000`에 연결한 뒤 Center와 각 방향을 한 번씩 시험한다. Pi 서버가 줄바꿈으로 끝나는 `PTZ:` 명령을 처리하는지 서버 로그로 확인하고 물리적 방향을 점검한다.
4. 같은 장면에서 WebRTC·RTSP TCP·RTSP UDP의 표시 지연과 프레임 멈춤을 측정한다. 측정 전까지 특정 방식이 더 빠르다고 단정하지 않는다.
