# 개발 세션 기록 — 2026-10-08

## 오늘 작업 요약

Qt Mini VMS Desktop Client에서 PTZ 제어 경로를 VMS WebSocket API에 연결했다.
Qt가 Raspberry Pi에 직접 ONVIF 또는 TCP 명령을 보내지 않고, 다음 흐름을 사용한다.

```text
Qt PTZ UI → VmsClient(WebSocket) → VMS PtzCommandRouter → Pi ONVIF/PTZ → GPIO PWM
```

## 구현 내용

- 방향 버튼을 누르면 `PTZ_MOVE`를 전송한다.
- 방향 버튼을 놓으면 `PTZ_STOP`을 전송한다.
- 키보드 방향키와 `W/A/S/D`를 지원한다.
- `C` 또는 `R`을 누르면 `PTZ_CENTER`를 요청한다.
- 이동 중에는 200ms 간격으로 최신 이동 명령을 갱신한다.
- 키 자동 반복에서 발생하는 가짜 release 이벤트는 무시한다.
- 포커스 상실, 창 비활성화, 카메라 전환, VMS 연결 해제 시 이동 타이머를 멈추고 STOP을 요청한다.
- PTZ 명령 전송 로그와 VMS 승인 응답, Pi 확인 응답을 분리해 기록한다.
- 카메라의 PTZ capability가 없으면 PTZ UI를 비활성화한다.

## VMS PTZ 응답 처리

- 명령 수신 직후 VMS의 `ACCEPTED` 응답을 처리한다.
- 이후 `PTZ_RESULT` notification의 `PI_ACKNOWLEDGED`, `FAILED`, `SUPERSEDED` 상태를 처리한다.
- 응답이 없으면 timeout으로 처리하고 대기 중인 PTZ 상태를 정리한다.

- Linux Qt 환경에서 자동 빌드와 테스트를 완료했다.
