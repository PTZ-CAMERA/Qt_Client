# Project working rules

## Technology decisions

When selecting or materially changing a technology in this project, record the decision in `PTZCamera/docs/tech-decisions/` as a Markdown file in the same change. Include:

1. The problem and constraints.
2. The selected technology and how this project uses it.
3. Realistic alternatives considered.
4. The reason for choosing the selected option over each alternative.
5. Known limits, assumptions, and evidence or tests still needed.

Update the decision record when the choice changes. Keep claims about performance tied to measurements or cited documentation; do not present unmeasured latency as a fact.
